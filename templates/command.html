Command Injection

🔴 Difficulty : Hard

OWASP : A03:2021 Injection

Description

Command Injection occurs when user input is executed as part of an operating system command.

Objective

Try injecting additional commands into the IP address field.

Unsafe Code


command = f"ping {ip}"

os.popen(command)

Target IP



Output


{{ output }}

Example Payloads

Windows


127.0.0.1

127.0.0.1 & whoami

127.0.0.1 & dir

127.0.0.1 & hostname

Linux


127.0.0.1

127.0.0.1 ; whoami

127.0.0.1 && ls

127.0.0.1 && id

Secure Code


subprocess.run(["ping", ip])

Explanation

Never concatenate user input into operating system commands. Always use parameterized command execution such as subprocess.run() with a list of arguments.
