📂 Path Traversal Lab

🟡 Difficulty : Medium

OWASP : A01:2021 Broken Access Control

Description

Path Traversal, also known as Directory Traversal, occurs when an application allows users to access files outside the intended directory.

Objective

Try reading files from the vulnerable_files directory.

Output

{{ output }}

Try These Inputs

secret.txt

config.ini

../notes.txt

../../notes.txt

How It Works

The application takes the filename supplied by the user and combines it with the vulnerable files directory.

Because the application does not verify that the final path remains inside the intended directory, directory traversal sequences such as ../ can be used to access files outside that directory.

Secure Version

from pathlib import Path

BASE = Path("vulnerable_files").resolve()

requested = (BASE / filename).resolve()

if BASE not in requested.parents:

    raise Exception("Invalid Path")

with open(requested, "r") as file:

    output = file.read()

Remediation

  • Never trust filenames supplied by users.
  • Resolve the requested path before accessing the filesystem.
  • Verify that the resolved path remains inside the allowed directory.
  • Prefer allowlists of permitted files where possible.
