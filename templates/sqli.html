💉 SQL Injection Lab

🟡 Difficulty : Medium

Category : Server-Side Injection

OWASP : A03:2021 Injection

Description

SQL Injection occurs when untrusted user input is incorporated directly into an SQL query.

In this lab, the application constructs an SQL query using the supplied username without using parameterized queries.

Objective

Identify the vulnerable database query and determine how user input changes the SQL statement executed by the application.

How It Works

The vulnerable backend constructs an SQL statement using string interpolation. 

query = f"""
SELECT * FROM users
WHERE username = '{username}'
"""

Because the input becomes part of the SQL statement itself, specially crafted input can change the structure or logic of the query.

Secure Version

query = """
SELECT * FROM users
WHERE username = ?
"""

result = cursor.execute(
    query,
    (username,)
).fetchall()

Parameterized queries keep user-controlled data separate from the SQL statement.

Remediation

  • Use parameterized queries or prepared statements.
  • Never construct SQL queries by concatenating user input.
  • Apply appropriate database permissions.
  • Validate input where appropriate.
  • Avoid exposing detailed database errors to users.
