🟢 Difficulty : Easy

Category : Client-Side Injection

OWASP : A03:2021 Injection

Description

Cross-Site Scripting (XSS) occurs when an application includes untrusted user input in a web page without properly encoding or sanitizing it.

In this lab, the application reflects the supplied input directly into the response.

Objective

Determine whether your input is interpreted as HTML or JavaScript instead of being displayed as ordinary text.

How It Works

The application receives the value of the name parameter and places it directly into the generated response.

Because the application does not safely encode the supplied input, browser-interpreted HTML or JavaScript can become part of the page.

Secure Version

from markupsafe import escape

name = request.args.get("name", "")

output = escape(name)

return render_template(
    "xss.html",
    output=output
)

Remediation

  • Contextually encode untrusted user input before displaying it.
  • Avoid inserting untrusted input directly into HTML.
  • Use framework-provided automatic escaping where available.
  • Implement an appropriate Content Security Policy (CSP).
